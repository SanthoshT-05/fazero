# FAZERO — Dubai Digital Growth Website

Lightweight multi-page frontend. No Node.js or npm required.

## Run locally

1. Extract the ZIP.
2. Open `index.html` directly in a browser, or use VS Code + Live Server for the cleanest local preview.
3. All primary navigation and CTA links are already connected.

## Production connections to replace

Edit these placeholders across the HTML files:
- WhatsApp: `971000000000`
- Email: `hello@fazero.com`
- Phone: `+971 XX XXX XXXX`
- Social URLs

## Images

Image areas are intentionally lightweight placeholders. Each contains a Google Images search link for the relevant subject so you can choose licensed imagery later. Do not hotlink Google Image result URLs; after choosing an image, download/use a stable CDN or local asset you have permission to use.

## Contact form

The form has required-field validation and a local success state. For production, connect `#leadForm` in `js/app.js` to your email API, CRM or backend endpoint.

## Research basis

The service mix and positioning are based on the current Dubai agency market: strategy, SEO, PPC/paid media, social marketing, web development and content are repeatedly presented as core services by Dubai-focused agencies. The site deliberately avoids fabricated case-study numbers and client claims.
